# 中国大陆软件/IT 岗位简历规范研究报告

> 研究日期：2026-07-02。来源为一线大厂面试官投稿与头部技术社区（字节 ADFE、JavaGuide、云舒编程、决战BAT柠檬哥、牛客等），均带原始 URL。
> 本文件是 `skills/resume-optimizer/references/cn-na-market.md` 的**中国侧原始素材**。北美侧已补充专门调研，见 `2026-07-02-na-resume-norms.md`；CN↔NA 双向转换见 `2026-07-02-cn-na-conversion-guide.md`。

## 落地清单（TL;DR）

- **头部字段**：姓名、电话、邮箱、求职意向（岗位+城市）、毕业时间/学历为核心；GitHub/博客仅在有内容时加；照片、年龄、微信为可选；性别/身份证/政治面貌/家庭住址/期望薪资默认不进正文。
- **页数**：校招 1 页（≤2），社招 2 页（≤3），PDF 导出。
- **模块顺序**：校招（学校强）个人信息→教育→专业技能→项目/实习→荣誉→(自我评价)；校招（学校弱）与社招把教育下沉。
- **项目**：STAR 结构 + 技术栈行 + 6–8 条个人职责，每条尽量"技术+场景+量化效果"（如"响应时间从 2s 降到 0.2s""QPS 30w+"）。
- **技能**：按 JD 关键词定制；分级用"了解/熟悉/熟练掌握/精通"，校招禁用"精通"；技术名词规范大小写、中英文间加空格。
- **命名**：`姓名-目标岗位-学校-专业`（校招）/ `姓名-目标岗位-优势点`（社招），投递方有要求则从其要求。
- **红线过滤器**：删空话自评、无关证书（Office/普通话/计算机二级）、格局小的校园职务、夸大/未实践技术、过时技术栈、Word 格式。

## 维度 1：个人信息 / 头部

只写：姓名、电话、邮箱、求职意向、毕业时间/学历。越简洁越好。

| 字段 | 惯例 |
|---|---|
| 姓名/电话/邮箱 | 必写，绝不能错 |
| 求职意向 | 强烈建议（岗位+城市），校招尤其 |
| 毕业时间/届别 | 校招/实习必写（证明应届身份） |
| 年龄/籍贯 | 有争议，可省（多数面试官不 care） |
| 微信 | 非必需 |
| 性别/身高/身份证/住址/政治面貌/民族 | 不建议写 |
| 期望薪资 | 正文不写（填在投递平台字段） |
| GitHub/博客 | 加分项，**有内容才写**，链接可点击 |
| LinkedIn | 中国大陆技术简历基本不用 |

照片：可选，非强需求。技术岗趋势"不放或放职业照"，忌呆板证件照/生活照。与美式"绝不放照片"不同。
来源：JavaGuide https://juejin.cn/post/7289239226024804409 ；字节 https://juejin.cn/post/6844904120734711815 ；云舒 https://juejin.cn/post/7292948455550238732 ；https://juejin.cn/post/6844903894305210376 ；https://juejin.cn/post/6946814373306482718

## 维度 2：篇幅

校招 1 页为主（顶多 2 页且铺满）；社招 2 页（顶多 3 页）。避免"1 页半"留白。
来源：JavaGuide、字节、https://juejin.cn/post/7277804250024427557

## 维度 3：分区与顺序

标准模块：求职意向、个人信息、教育背景、专业技能/技术栈、项目经历、实习/工作经历、荣誉奖项、校园经历、自我评价。

- 校招（学校强 985/211）：个人信息→教育（靠前）→专业技能→项目/实习→荣誉→(自我评价)。
- 校招（学校一般）：教育**下沉**。
- 社招：个人信息→(个人优势置顶)→工作经历(倒序)→项目经历(倒序)→专业技能→教育(下沉)。

自我评价：可选，"重灾区"。忌"勤奋/吃苦/学习能力强/沟通能力好"等空话；要写则给具体事例（FAB），≤3 条。
来源：字节、JavaGuide、柠檬哥 https://juejin.cn/post/6964664853218721823 、https://juejin.cn/post/7277804250024427557

## 维度 4：项目经历写法与量化

STAR（背景-任务-行动-结果）是公认标准。结构模板：
```
项目名称    时间(倒序)    公司/角色
项目描述：一两行讲清做什么（≤2 行）
技术栈：Spring Boot + MySQL + Redis + ...
工作内容/个人职责：6~8 条，突出"做了什么、解决了什么、带来什么改善"
（可选）个人收获/项目成果
```
原则：突出"你做了什么"而非"项目是什么"；每条必须携带技术点；量化。
量化范例：
- "使用 xxx 解决 xxx 问题，系统 QPS 从 xxx 提高到 xxx"
- "CompletableFuture 并行加载，平均响应时间从 3.5s 降到 1s"
- "Redis+Caffeine 两级缓存解决击穿穿透，查询毫秒级，QPS 30w+"
- "Sharding-JDBC 按用户 ID 后 4 位分库分表，单表 <500w"

动词："负责"(主要模块)/"参与"(协作)/"主导"/"优化"/"实现"/"排查并解决"。
红线：不写没实践过的技术；减少"学到很多""认识到重要性"等无效描述。
精选 2~3 个项目（不超过 4），一主多辅，第一个最拿得出手。
来源：字节、JavaGuide、云舒、https://juejin.cn/post/7022927620689887263

## 维度 5：专业技能 / 技术栈（分级）

分级由低到高：**了解 → 熟悉 → 熟练掌握 → 精通**（中间档可用"使用过"）。

- **"精通"是高压线**——校招/实习几乎不用，会被问得很惨。最熟用"熟悉"，次熟用"使用过"，不太熟用"了解"。
- 字节分档标注示例：`HTML（熟悉），CSS（熟悉），React（了解）`。
- 争议流派：字节前端 2024 主张前端岗不用等级/百分比，直列主流技术栈名词。

**关键词匹配（中国版"过 ATS"）**：HR 可能按 JD 关键词甚至算法匹配打分。按 JD【任职要求】原文改写技能行。公司要求而你不会的，可花几天学后写"了解"。
大小写规范：java→Java，spring boot→Spring Boot；中英文/数字间加空格。
来源：https://juejin.cn/post/7022927620689887263 、https://juejin.cn/post/7277804250024427557 、JavaGuide、字节前端

## 维度 6：项目 vs 实习/工作经历（校招权重）

术语：工作经历→社招；实习经历→校招。
校招无工作经验时项目经历是核心武器。商业项目 > 毕设 > 课设。无商业项目用毕设/课设/竞赛凑，可写"项目规模：约 20 模块，3 人 3 个月"。
实习：校招/毕业一两年内可放（尽量大公司、≥3 个月）；工作 3 年以上别写实习。
来源：字节、https://juejin.cn/post/6907146327043129352 、云舒、柠檬哥

## 维度 7：教育背景

必含：学校、学历、专业、起止时间、(可选)绩点/排名、相关课程、CET。多份按学历高→低。
GPA/排名：前 30% 才写，否则不写（扬长避短）。排名用"专业排名前 5%/10%/30%"。
学校层级：985/211/双一流靠前写。校招学历权重高于社招。
CET-4/6：加分项，外企更看重。
相关课程：相关且对口才写，忌罗列。
本科以下：部分面试官建议可不写学历以争取机会。
来源：云舒、JavaGuide、字节、柠檬哥、https://juejin.cn/post/6907146327043129352

## 维度 8：语气/文化/红线/ATS

谦逊 vs 自我推销：忌空泛自夸，也忌过度谦虚不写成果。用客观证据/量化说话。
红旗（减分项）：
1. 夸大能力、写没实践过的技术
2. 滥用"精通"（校招尤甚）
3. 空话自评
4. 无关信息（兴趣爱好、身高体重、人生格言、格局小的校园职务）
5. 无关证书（Office、普通话二级、计算机二级）
6. 技术栈与岗位不匹配 / 过时技术（前端一堆 jQuery/BootStrap）
7. 抄模板千篇一律
8. 低级错误（错别字、术语错、标点混用、大小写不规范、Word 乱码）
9. 培训机构经历：**有争议**（可不写 vs 对缺项目者是亮点）

ATS/关键词：中国无美式独立 ATS 生态，但大厂+平台有关键词/算法匹配打分。技能/项目用 JD 原词提高匹配分。
扫描时间：一份几十秒甚至十几秒，关键信息须一眼可见。

## 维度 9：文件格式与命名、投递渠道

**PDF 是铁律**（Word 在 Mac 可能乱码，PDF 正式保密不走样）。
制作工具：resume.mdnice.com、木及简历、简单简历、极简简历、超级简历、站长简历。
命名（高共识）：

| 场景 | 推荐命名 |
|---|---|
| 字节官方 | 岗位+姓名+毕业时间+学校+专业 |
| 校招(云舒) | 姓名-目标岗位-学校-专业 |
| 社招(云舒) | 姓名-目标岗位-优势点 / 姓名-目标岗位 |
| Java 后端 | 姓名_学历_应聘岗位_电话 |
| 柠檬哥 | 岗位-姓名（切忌"简历""个人简历-姓名"）|

规律：`姓名+目标岗位`最小必备；校招加学校/专业/毕业时间，社招加优势点；投递方有要求则从其要求。绝不用纯"简历.pdf"。

投递渠道：
- **BOSS直聘** = 霸主（2025 月活 6360 万、份额 64.5%）
- 智联(~17%)、前程无忧/51job(~13%)第二梯队
- **拉勾网 2026 年 5 月已破产重整、APP 下架**——不应再主推
- 内推/referral：大厂强渠道
- 牛客网：校招刷题/面经/内推/在线笔试面试
来源：JavaGuide、字节、https://juejin.cn/post/7642267656926969866

## 争议点（建议做成可配置项）

1. 照片：社招职业照 vs 技术岗不放
2. 技能分级：后端用等级 vs 前端直列名词
3. 年龄/籍贯：列出 vs 可省（默认可不写）
4. 自我评价：认可(具体事例) vs 可不写（默认可选，写则 ≤3 条具体）
5. 培训机构经历：亮点 vs 可不写（谨慎）
6. 教育经历位置：学校强靠前 / 学校弱下沉
